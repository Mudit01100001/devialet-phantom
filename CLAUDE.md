# Devialet Phantom — `devialet-site`

Scroll-driven 3D product film for the (mock) **Devialet Phantom** speaker — one continuous, scroll-scrubbed camera take around a real-time WebGL model, with an audio-reactive soundtrack. **Live:** https://devialet-site.vercel.app · **Repo:** Mudit01100001/devialet-phantom.

> Unaffiliated **concept / portfolio** piece (target: land 3D-web work with Grapes Worldwide). *Phantom* and *Devialet* are trademarks of Devialet; nothing here is official or for sale. The **entire 3D model was built from scratch in Blender by Mudit.**

## Read first — every UI task
1. **`next/dist/docs/`** before writing any Next.js code — this is **Next.js 16**; APIs differ from training data.
2. **`PRODUCT.md`** (brief, off-limits list) and **`DESIGN.md`** (design system, tokens) before touching any UI.

## Design rules — **Never**
- `font-mono` for UI labels — use `font-sans` (system-ui) with tracking
- `rounded-full` or any border-radius on buttons or cards (the chrome ring is the only curve)
- Gradient backgrounds or gradient text (`radial-gradient` / `linear-gradient` on surfaces)
- `text-neutral-*` hard-coded grays — use design tokens (`--color-white-muted`, `--color-white-ghost`, `--color-chrome`, …)
- Glassmorphism, backdrop-blur as decoration, glow overlays
- Purple, blue, or gold as accent colors (chrome is the single accent; gold is a finish, not a UI color)
- Card carousels or three-equal-feature-card layouts
- Decorative lights/glows on the page layer — the 3D model handles all atmospheric depth

## Architecture — where things live
- **`components/Experience.tsx`** — the whole take. Scene, camera rig, the GSAP ScrollTrigger timeline, deterministic text reveal (`updateText(progress)`), the audio system + dev tuner, the HUD mount, cart drawer, entry gate, the **6 film beat blocks (hero → finish)**, the **post-film `AcquireReveal` section** (the buying panel — kept here, not in PostTake, because it needs cart/finish state + the camera), and the mounts for the PostTake sections. Render-cheap **module globals** (`view` incl. `view.acquire`, `PROGRESS`, `AUDIO`, `MOBILE`) are read every frame to avoid React re-renders during scroll. Three ScrollTriggers: the film timeline (hero→finish), the **acquire reveal** (scrubs `view.acquire` 0→1, fades the film overlay out), and a **light-interlude toggle** (flips the HUD/sound chrome to dark ink while the paper sections are under the top bar).
- **`components/PostTake.tsx`** — flat content sections, in scroll order: `Sound` → `Presence` (dark editorial, **crisp** spacing, mirrored grids so the two align edge-to-edge, both photos 3:2) → `Connectivity` → `FindYourSound` (the **light/paper retail interlude**) → **[acquire reveal, in Experience.tsx]** → `Assurances` (now **dark**) → `Professionals` → `Newsletter` → `SiteFooter`. Each is a sibling of `main`; dark sections are `relative z-20 bg-void`, the interlude is `bg-paper`. Kept in their own file so editing them doesn't trip the `Experience.tsx` HMR-scrub freeze. **`Connectivity` is a reference-style selectable bento** (a row of white boxes, icon atop + name below; click selects one — dark border — and its explanation updates below the row; `Glyph` SVGs incl. abstract marks for Roon/UPnP/Tidal). **`FindYourSound`** = range-hero image + a light "evolution of the revolution" card (with its own small image) + an inverted dark "select your model" card. **`Assurances` is now a DARK bento** (`bg-void` section, `surface-raised` grey tiles) placed **below the acquire/order section** (not in the interlude). **`Professionals` is a white bento on black** ("For professionals." big + "Specified for your room." sub + advisor card). **`Newsletter`** = a moon-image rectangle (placeholder, lighter tone) holding a white "Join the revolution" card (form) + a contact strip (hours + a lighter "Chat with us"). **`SiteFooter`** = an **off-white (paper) back-to-top strip** ("Devialet · Concept" + back-to-top) over dark nav columns + credits. All box/card/image corners read the universal **`--radius`** token. Concept links are inert `GhostLink` buttons (no jumping). Swappable `ImagePlaceholder` (`tone` dark/light) awaits renders. **Copy rule: no em dashes anywhere.**
- **`components/Hud.tsx`** — fixed top **nav bar** (brand left, category links centre, cart right) that **auto-hides on scroll-down and returns on scroll-up** (`setHidden` driven from the Lenis scroll handler in `Experience.tsx`). Takes `overLight` to flip white→ink over the light interlude. (The old top scroll-progress line was removed — read as AI-slop.)
- **`components/SceneGuard.tsx`** — WebGL feature-detection, DOM + R3F error boundaries, on-brand fallback poster.
- **`app/layout.tsx`** — metadata (title `PHANTOM`, Open Graph + Twitter cards, `metadataBase`), Italiana font, `suppressHydrationWarning`, theme color.
- **`app/globals.css`** — design tokens (`@theme`), `:focus-visible` rings, scroll-cue + eq-bar keyframes, volume-slider styling, reduced-motion block.
- **`app/icon.svg` / `icon.png` / `favicon.ico`** — P-monogram favicons.
- **`app/opengraph-image.png` / `twitter-image.png`** — social cards.
- **`public/`** — `finish_gold.glb` / `finish_rosegold.glb` / `finish_black.glb` (~1.95 MB each) + `phantom-track.m4a` (full) / `phantom-track-loop.m4a` (lighter loop).

## Key systems (mostly in `Experience.tsx`; post-take layer in `PostTake.tsx`)
- **Scroll structure (film + reveal):** the film take is **6 beats — hero → shape → power → detail → spine → finish (pick color) — and ENDS at finish**. Camera driven by ScrollTrigger over a Lenis smooth-scroll spacer (`~720vh`); copy reveal is a pure function of scroll (Z-depth + blur outside a sharp read plateau). Below the film: dark editorial (Sound/Presence) → **light retail interlude** (Connectivity/FindYourSound/Assurances on paper) → **`AcquireReveal`** (the 3D REAPPEARS — a transparent section; its ScrollTrigger scrubs `view.acquire` 0→1 so CameraRig blends the held finish framing toward `ACQUIRE_VIEW`, while the film overlay fades out; a `sticky pointer-events-none` panel keeps the buying card centred and lets drag fall through to the canvas) → dark close (Professionals/Newsletter/SiteFooter). Palette story = dark film → dark editorial → light retail → dark acquire → dark close.
- **Finishes:** Gold / Rose Gold / Matte Black — all three GLBs stay mounted, visibility-toggled (swapping one `<primitive>` raced and blanked the canvas). Picker in the finish beat + the AcquireReveal panel; finish-aware lighting so matte black neither blows out nor goes dead.
- **Audio (desktop only):** entry gate unlocks Web Audio on click; an `AnalyserNode` drives the woofers off DC-removed band energy (gain = symmetric swing around a fixed rest; `outLimit`/`inLimit` cap travel; `lowHz`/`highHz` band). Mute + hover-reveal volume (gain node after the analyser). Device-tiered track via `hardwareConcurrency`. Baked defaults: gain 1.05, out 0.27, in 0.05, 60–1200 Hz, vol 0.6.
- **Interaction:** site-wide drag-to-rotate (X+Y tumble that springs back; finish/acquire = seated Y-only turntable).
- **Resilience & a11y:** WebGL context-loss recovery + fallback poster; `prefers-reduced-motion` path; keyboard beat-nav (↑/↓, PageUp/Down, Home/End, Space); cart focus-trap + Esc + `inert`; global `:focus-visible` chrome rings; ≥44 px tap targets.

## Conventions
- **Per-frame state is mutated on module globals, not React state** — keep it that way; prop/state cascades during scroll cause jank.
- **GLB pipeline:** Mudit exports uncompressed GLBs from Blender; compress each with `npx @gltf-transform/cli` (WebP textures → meshopt, ≈1.95 MB) into `public/`. The finish picker loads by filename (`FINISH_URL`), so swapping a finish is a drop-in (no code change). Never headless-write his `.blend`.
- Tailwind for layout utilities; colors via tokens. White/black opacity utilities (`bg-white/10`, `text-white/90`) are acceptable infra.
